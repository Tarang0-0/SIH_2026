## 2. Canonical Data Models

### 2.1 Canonical Train State (`CanonicalTrainEvent`)
```python
class CanonicalTrainEvent(BaseModel):
    journey_id: str
    train_id: Optional[str] = None
    train_number: str
    timestamp: datetime
    latitude: float = Field(..., ge=-90.0, le=90.0)
    longitude: float = Field(..., ge=-180.0, le=180.0)
    speed_kmph: float = Field(..., ge=0.0, le=250.0)
    current_station: str
    next_station: str
    delay_minutes: float
    status: str = "ACTIVE" # SCHEDULED, ACTIVE, COMPLETED, CANCELLED
    source: DataSourceType = DataSourceType.SIMULATED # REAL, DERIVED, SIMULATED, SYNTHETIC
```

### 2.2 Data Provenance Classification
- **`REAL`**: Real static timetable, station GIS coordinates, and verified public open data.
- **`DERIVED`**: Computed features, topological distances, and schedule differences.
- **`SIMULATED`**: Real-time telemetry events generated by the deterministic replay runner.
- **`SYNTHETIC`**: Offline training dataset records generated for model training.

## 3. Database Schema Overview

1. **`stations`**: Unique station codes, English names, WGS-84 coordinates, zones, and divisions.
2. **`trains`**: Train numbers, names, train categories (Rajdhani, Shatabdi, Vande Bharat, Express), and terminus stations.
3. **`routes` & `route_stations`**: Ordered topology, cumulative track distances, and scheduled arrival/departure timetables.
4. **`journeys`**: Active train runs with current live telemetry, delay, and timestamp.
5. **`running_updates`**: Immutable log of incoming telemetry updates.
6. **`section_history`**: Historical mean and p90 section runtimes for feature extraction.
7. **`eta_predictions`**: Persisted model forecasts, baseline comparisons, uncertainty intervals, and SHAP explanations.
