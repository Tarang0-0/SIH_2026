# Plan 05-01: MapLibre GL JS Route Visualizer & WebSocket Client Hook

## Goal
Integrate an interactive MapLibre GL JS vector map visualizer rendering Indian Railways route corridors and animated train location markers, paired with a resilient WebSocket client hook connecting directly to the FastAPI live prediction stream.

## Proposed Architecture & Changes

### 1. MapLibre GL Interactive Route Visualizer
- **File**: `frontend/src/components/MapLibreView.tsx`
- Renders MapLibre GL JS dark canvas (`https://basemaps.cartocdn.com/gl/dark-matter-gl-style/style.json` or fallback GeoJSON vector lines).
- Draws route polyline between station nodes:
  - Shatabdi corridor: `NDLS (28.6139, 77.2090) → GZB (28.6657, 77.4393) → ALJN (27.8974, 78.0777) → CNB (26.4547, 80.3507) → LKO (26.8322, 80.9234)`
  - Rajdhani corridor: `BCT (18.9696, 72.8194) → ST (21.2036, 72.8407) → BRC (22.3107, 73.1812) → RTM (23.3441, 75.0347) → KOTA (25.2238, 75.8770) → MTJ (27.4924, 77.6737) → NDLS (28.6139, 77.2090)`
- Plots station marker nodes with station codes and glow indicators.
- Animated pulsating train marker at current active location with speed popup.

### 2. WebSocket Real-time Client Hook
- **File**: `frontend/src/hooks/useLiveTrainWebSocket.ts`
- React hook subscribing to `ws://localhost:8000/ws/trains/{journey_id}` and `ws://localhost:8000/ws/live-stream`.
- Handles automatic reconnection with exponential backoff, initial hydration, heartbeat pings, and connection state (`connecting`, `connected`, `disconnected`).
