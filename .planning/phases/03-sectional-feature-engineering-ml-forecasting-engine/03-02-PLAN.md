# Plan 03-02: Cascading ML Inference Engine, SHAP Explainability, Evaluation Harness & Test Suite

## Goal
Implement the runtime ML ETA forecasting engine with section-by-section cascading inference, residual quantile confidence intervals, `shap.TreeExplainer` feature attributions, model evaluation benchmark script, and comprehensive Pytest suite.

## Proposed Changes

### Runtime Inference & Explainability Engine
#### [NEW] `backend/app/services/ml_eta.py`
- Implements `MLETAEngine` class:
  - Loads `eta_model.pkl` and `residuals.pkl` artifacts.
  - Cascades section travel time predictions forward across all upcoming stations from `current_station`.
  - Computes `predicted_eta` timestamps by accumulating predicted section travel times.
  - Computes confidence bounds (`lower_bound_minutes`, `upper_bound_minutes`, `confidence_range_lower`, `confidence_range_upper`) using $q_{10}$ and $q_{90}$ residual quantiles.
  - Generates top-5 SHAP feature contributions via `shap.TreeExplainer` and populates `shap_explanation` in `ETAPredictionResponse`.
  - Gracefully falls back to baseline if model artifacts are missing.

### API Updates & Model Lifecycle
#### [MODIFY] `backend/app/main.py`
- Sets up FastAPI lifespan event to load ML model artifact into application state at startup.

#### [MODIFY] `backend/app/api/v1/endpoints/eta.py`
- Integrates `predict_ml_eta` into `GET /api/v1/trains/{id}/eta` endpoint.

### Model Evaluation Harness
#### [NEW] `scripts/evaluate_model.py`
- Benchmarks trained GBDT model against Phase 2 schedule baseline on the 20% holdout test dataset.
- Computes and prints:
  - Mean Absolute Error (MAE in minutes)
  - Root Mean Squared Error (RMSE in minutes)
  - % of predictions within $\pm 5\text{m}$, $\pm 10\text{m}$, $\pm 15\text{m}$ accuracy windows.

### Verification Suite
#### [NEW] `backend/tests/test_ml_forecasting.py`
- Test cases verifying:
  1. Zero-leakage feature extraction invariant.
  2. XGBoost model loading and inference.
  3. Cascading section travel time summation.
  4. Confidence bounds ($lower \le predicted \le upper$).
  5. Top-5 SHAP explanation dictionary structure.
  6. Side-by-side benchmark evaluation script execution.
