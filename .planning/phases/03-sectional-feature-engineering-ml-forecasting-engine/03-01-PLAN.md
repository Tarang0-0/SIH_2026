# Plan 03-01: Synthetic Data Generation, Zero-Leakage Feature Extraction & Model Training

## Goal
Implement the synthetic section training data generator, the zero-leakage `FeatureExtractor` pipeline, and the offline XGBoost GBDT model training script.

## Proposed Changes

### Data Generation & Storage
#### [NEW] `scripts/generate_training_data.py`
- Reads historical section baselines for Shatabdi (12004) and Rajdhani (12951) routes.
- Generates 5,000 synthetic section traversal records with realistic Gaussian delay noise ($\sigma=5\text{ min}$), uniform time-of-day/day-of-week, and ±10% seasonal variance.
- Outputs dataset to `backend/ml/data/synthetic_section_data.csv` with explicit `"source": "SYNTHETIC"` provenance.

### Feature Extraction Service
#### [NEW] `backend/app/services/features.py`
- Implements `FeatureExtractor` class extracting 9 tabular features:
  - `current_delay_minutes`
  - `current_speed_kmph`
  - `section_distance_km`
  - `scheduled_section_minutes`
  - `historical_avg_running_minutes`
  - `historical_p90_running_minutes`
  - `departure_hour`
  - `day_of_week`
  - `train_type_encoded`
- Enforces strict zero-leakage constraint (uses only data observable at or before prediction time $T$).

### Model Training Pipeline
#### [NEW] `scripts/train_model.py`
- Loads `synthetic_section_data.csv`.
- Performs chronological 80/20 train/test split.
- Trains `XGBRegressor` on target `actual_running_minutes`.
- Calculates training residual quantiles ($q_{10}$ and $q_{90}$).
- Persists model artifact to `backend/ml/models/eta_model.pkl` and residual bounds to `backend/ml/models/residuals.pkl`.

## Verification
- Run `python scripts/generate_training_data.py` and verify CSV output has 5,000 rows.
- Run `python scripts/train_model.py` and verify `eta_model.pkl` and `residuals.pkl` are generated in `backend/ml/models/`.
