# Plan 05-02: Train Detail Dashboard, Station ETA Table & Interactive SHAP Explainability

## Goal
Deliver a modern, minimalist, and responsive Next.js fleet dashboard incorporating the Google Stitch "Midnight Kinetic" design system with modular station ETA tables, uncertainty confidence bounds, and diverging SHAP explainability charts.

## Proposed Architecture & Changes

### 1. Modular Components
- **`frontend/src/components/FleetSidebar.tsx`**: Search input, active train cards with speed/delay pills and pulsing connection dots.
- **`frontend/src/components/StationETATable.tsx`**: Station-by-station dynamic forecast table comparing scheduled, baseline, and GBDT predicted arrival times with confidence intervals (`[lower, upper]`).
- **`frontend/src/components/SHAPExplainerCard.tsx`**: Center-axis diverging SHAP impact bars highlighting emerald delay reduction and amber delay increase factors.
- **`frontend/src/components/HeaderNav.tsx`**: Status indicator pills (`SIH 26028`, `PostGIS Connected`, `GBDT v1.0 Active`, `Replay Feed` button).

### 2. Main Page Integration (`frontend/src/app/page.tsx`)
- Integrates `MapLibreView`, `FleetSidebar`, `StationETATable`, `SHAPExplainerCard`, and `HeaderNav` with live WebSocket streaming data.
- Allows seamless switching between Map View and Route Progression Strip view.
