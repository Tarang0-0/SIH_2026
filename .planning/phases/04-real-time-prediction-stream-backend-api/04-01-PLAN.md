# Plan 04-01: Real-time Prediction Stream & Backend API

## Goal
Expose robust, high-performance FastAPI REST endpoints and real-time WebSocket connection channels that broadcast dynamic GBDT ETA recalculations, confidence intervals, and SHAP explainability to connected frontend clients as live running events arrive.

## Proposed Architecture & Changes

### 1. WebSocket Connection Manager
- **File**: `backend/app/services/websocket_manager.py`
- Implements `ConnectionManager` class maintaining active WebSocket connections per `journey_id` and global broadcast channel.
- Asynchronous thread-safe `broadcast_prediction(journey_id, prediction_data)`.
- Heartbeat ping/pong support and clean client disconnect handling.

### 2. Dedicated Trains REST Router
- **File**: `backend/app/api/v1/endpoints/trains.py`
- Endpoints:
  - `GET /api/v1/trains` — Active trains list with current position, speed, delay, origin, destination, and data source.
  - `GET /api/v1/trains/{id}/route` — Route station sequence, scheduled arrival/departure, and cumulative distance.
  - `GET /api/v1/trains/{id}/eta` — Cascading ML ETA forecast + baseline comparison + confidence bounds + SHAP explainability.

### 3. Real-time WebSocket Endpoints
- **File**: `backend/app/api/v1/endpoints/websockets.py`
- Routes:
  - `WebSocket /ws/trains/{journey_id}` — Subscribes to live ETA updates for a specific journey.
  - `WebSocket /ws/live-stream` — Global stream receiving all train events and prediction updates.

### 4. Ingestion Triggered Live Broadcasting
- **File**: `backend/app/api/v1/endpoints/ingestion.py`
- When `POST /api/v1/running-updates` successfully processes an event, compute fresh ML ETA prediction and broadcast payload via `ConnectionManager` to connected WebSocket clients in real time.

### 5. Automated Testing & Verification
- **File**: `backend/tests/test_realtime_api.py`
- Test suite verifying:
  1. `GET /api/v1/trains` returns active fleet with proper schema and metadata.
  2. `GET /api/v1/trains/{id}/route` returns valid sequence of station topology items.
  3. `GET /api/v1/trains/{id}/eta` returns full `ETAPredictionResponse` with predictions and SHAP.
  4. WebSocket connection establishment and initial state push.
  5. Ingestion event triggers immediate live broadcast across WebSocket channel with updated GBDT prediction.
